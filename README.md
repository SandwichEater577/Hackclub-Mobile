# Hackclub Mobile

React Native app built with Expo and NativeWind.

## Setup

    nvm use 22
    npm install --legacy-peer-deps
    npx expo start

## Structure

    src/
      components/   reusable UI
      screens/      full screens
      hooks/        custom hooks
      utils/        helpers
      constants/    colors, config values
      styles/       global.css
      assets/       images, fonts
